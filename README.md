# Kimi Antonelli — Campione del Mondo 2026 · Fan Tribute

Unofficial fan site celebrating Andrea Kimi Antonelli's 2026 Formula 1 World Championship.
Static site (HTML + Three.js + GSAP + Lenis), no build step, ready to deploy on Vercel.

## Run locally
Open `index.html` in Chrome, or serve the folder: `npx serve .`

## Deploy on Vercel
Import the repository in Vercel → Framework preset **Other** → no build command → output directory `.` (root).
